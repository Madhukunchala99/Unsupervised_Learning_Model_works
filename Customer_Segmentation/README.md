# Customer Segmentation – Unsupervised Learning

## Project Overview

This project focuses on **Customer Segmentation using Unsupervised Learning**. The goal is to group customers with similar characteristics and behavior without using a predefined target variable.

The project uses customer data to identify different customer segments and understand their key characteristics. The analysis can help businesses better understand their customers and develop targeted strategies.

## Objectives

* Clean and preprocess customer data
* Explore customer characteristics and behavior
* Scale features for clustering
* Reduce dimensions using PCA
* Apply different clustering techniques
* Evaluate clustering performance
* Identify meaningful customer segments
* Interpret the characteristics of each cluster

## Machine Learning Techniques

The following unsupervised learning techniques were applied:

* **K-Means Clustering**
* **Hierarchical Clustering**
* **DBSCAN**
* **Principal Component Analysis (PCA)**

## Project Workflow

1. Load and understand the dataset
2. Check and handle data-quality issues
3. Perform exploratory data analysis
4. Prepare numerical and categorical features
5. Scale the features
6. Apply PCA for dimensionality reduction
7. Perform clustering using different algorithms
8. Evaluate clusters using the Silhouette Score
9. Analyze and interpret the customer segments
10. Assign meaningful names to the identified groups

## Key Analysis

The clustering results were analyzed based on customer characteristics such as:

* Customer behavior
* Satisfaction
* Monthly charges
* Usage patterns
* Contract and plan information
* Churn distribution

The final segments were interpreted based on their overall characteristics rather than relying only on cluster numbers.

Customer segmentation can help businesses identify different customer groups, understand their behavior, recognize higher-risk or valuable customers, and develop more targeted retention and engagement strategies.

This project demonstrates a complete **Unsupervised Learning workflow**, from preprocessing and dimensionality reduction to clustering, evaluation, and business interpretation.
